Phishing & Header Spoofing Lab

Vektor #02: Credential Stuffing

Brute Force & Rate Limiting Arena

Simulasikan serangan kamus otomatis berkecepatan 12,000 req/min. Pelajari bagaimana implementasi Token Bucket, IP Throttling, dan adaptive CAPTCHA mematahkan botnet.

Bot Stream Rate: 12,480 req/s
Mitigasi: Leaky Bucket (Rate: 5 req/min) STATUS: 429 Too Many Requests
Tingkat: Menengah

Vektor #03: Data Exfiltration

SQL Injection (SQLi) Playground

Kupas bahaya String Concatenation vs Prepared Statements. Coba eksploitasi blind SQLi, UNION SELECT, hingga bypass otentikasi dengan visualisasi AST query parser.

✕ Vulnerable: `SELECT * FROM accts WHERE user='${req.user}'` ✓ Patched: db.prepare("SELECT * FROM accts WHERE user=?").bind(req.user)
Tingkat: Dasar - Mahir

Metodologi Belajar: Dari Anatomi ke Patching

radar

Recon & Surface Mapping

Identifikasi celah terbuka pada port, routing API yang tidak terlindungi, parameter rentan, dan miskonfigurasi CORS.

Outcome: Threat Model Document

bug_report

Sandbox Exploitation

Outcome: PoC Exploit Analysis

Pakta Etika Keamanan Siber (Security Cat Pledge)

Seluruh materi, skrip simulasi, dan payload disediakan untuk tujuan pertahanan sistem legal (White Hat). Menguji skrip ini ke server pihak ketiga tanpa izin tertulis melanggar UU ITE dan regulasi internasional.

Apakah saya perlu menginstal alat hacking seperti Kali Linux atau Burp Suite? expand_more

Sama sekali tidak! Semua simulasi peretasan dan instrumen analisis berjalan secara virtual 100% di browser Anda menggunakan isolated WebAssembly sandbox. Tidak ada instalasi software berbahaya atau setup rumit yang diperlukan.

Apakah aman melakukan simulasi serangan ini di jaringan kantor atau kampus? expand_more

Sangat aman. Simulasi sandbox Security Cat tidak memancarkan paket berbahaya melintasi LAN Anda. Semua simulasi disimulasikan dalam container virtual yang terisolasi di sisi server sandbox kami, sehingga IDS/IPS kantor tidak akan menandai aktivitas Anda sebagai ancaman.

Apakah sertifikat kelulusan modul ini diakui secara profesional? expand_more
