# SecurityCat Modul 5 — Modern UI Frameworks (React 19 + Vite)

Tugas Modul 5: bandingkan framework modern, implementasi satu pilihan.
Pilihan: React 19. Tema dark Security Cat (`#0f131d`, aksen `#00f0ff`).

## Prasyarat

- Node.js LTS (cek: `node -v`)
- Folder ini punya `package.json` sendiri — semua perintah dari folder ini.

## Menjalankan

```bash
npm install     # sekali saja / setelah pull baru
npm run dev     # server dev, buka URL yang ditampilkan (biasanya http://localhost:5173)
npm run build   # build produksi -> folder dist/
npm run preview # pratinjau hasil build
```

## Isi

- `index.html` — entry
- `src/main.jsx`, `src/App.jsx` — root + layout
- `src/components/TaskDashboardReact19.jsx`, `TaskForm.jsx`, `TaskTable.jsx`
- `docs/Matriks-SRS-Modul-5.md`, `docs/Perbandingan-Framework.md`
